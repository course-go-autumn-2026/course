# Практика к лекции «ООП и принципы программирования»

В практике 10 вариантов на простых предметных областях. Выберите один вариант:
в каждом три независимых задания одинаковой структуры и сопоставимой сложности.
Можно работать парами. Незавершённое первое задание не мешает второму и третьему.

## Задания

1. **SOLID.** Найти минимум три проблемы в исходном коде, объяснить их последствия,
   исправить одну и проверить тестом. Для продвинутых — устранить все проблемы,
   добавить новую опцию через сборку зависимостей и проверить порядок сохранения
   и уведомления.
2. **Cohesion и coupling.** Разделить расчёт цены и оформление чека, добавить
   составляющую без изменения форматирования, сохранить текстовый и HTML-форматы.
   Для продвинутых — защитить состав от изменения через переданный срез.
3. **Интерфейс из бизнес-кейса.** Определить минимальный контракт у потребителя,
   подключить один готовый клиент и проверить сценарий простой заглушкой.
   Для продвинутых — адаптировать второй клиент, перевести единицы измерения
   и привести ошибки к общему контракту.

Подробные условия, контрольные значения и критерии находятся в README вариантов.
Интерфейсы вводите там, где они помогают требованиям: их количество не оценивается.

## Запуск

Нужен Go 1.22 или новее. Внешние библиотеки, БД и доступ к сети не нужны.
Из этого каталога:

```sh
cd variants/01-cafe
go test ./student/...
go run ./cmd/demo
```

Исходные тесты проходят и фиксируют базовые сценарии. Код намеренно содержит
проблемы для поиска и исправления. После изменения публичного API обновите
вызовы в тестах и `cmd/demo`, сохранив ожидаемые цены, чеки и ошибки.
Готовые клиенты третьего задания изменять нельзя.

## Что сдавать

- Изменённый код и тесты выбранного варианта.
- Таблицу проблем SOLID с последствиями и предлагаемыми исправлениями.
- Краткое объяснение распределения ответственностей во втором задании.
- Контракт интерфейса третьего задания: вход, результат, единицы и ошибки.

## Проверка всех вариантов

Команды выполняются из этого каталога, рядом с данным README:

```sh
sh variants/check.sh
```

Скрипт выполняет тесты, `go vet` и демо для всех вариантов.
Go не обходит вложенные модули автоматически: для общей проверки используйте
этот скрипт.

# Практика к лекции «Качество кода»

В проекте четыре независимых задания. На каждое рассчитано около 10 минут; во всех заданиях
нужно дописать или изменить не более 20 строк вручную. Команды выполняются из этого каталога.

Нужен Go 1.25 или новее. Перед началом загрузите зависимости:

```bash
go mod download
```

## 1. Табличный тест

Каталог: `01-table-test`.

Функция `SumSquares` вычисляет квадраты в отдельных горутинах, собирает результаты через канал
и возвращает `ErrNegativeNumber`, если во входе есть отрицательное число. В
`squares_test.go` оставлена только структура табличного теста.

Добавьте случаи для обычного слайса, пустого слайса и отрицательного числа. Проверьте результат,
наличие или отсутствие ошибки; обёрнутую ошибку сравнивайте через `errors.Is`.

```bash
go test -v ./01-table-test
```

## 2. Интерфейс и GoMock

Каталог: `02-mocks`.

Сейчас HTTP-обработчик зависит от конкретного `*GreetingService`. Объявите рядом с обработчиком
минимальный интерфейс с методом `Greet`, переведите поле и конструктор на этот интерфейс, затем
сгенерируйте mock:

```bash
go generate ./02-mocks
```

В `handler_test.go` создайте mock, задайте ожидание `Greet` и протестируйте успешный ответ через
`httptest.NewRequest` и `httptest.NewRecorder`. Проверьте HTTP-код и тело. Генератор закреплён в
`go:generate`, отдельно устанавливать `mockgen` не нужно.

```bash
go test -v ./02-mocks
```

## 3. Coverage, race detector и goleak

Каталог: `03-quality-checks`.

Сначала получите отчёт о покрытии функции `Total`:

```bash
make coverage
go tool cover -html=coverage.out -o coverage.html
```

Затем найдите гонку данных и защитите счётчик `processed`:

```bash
make race
```

Наконец, включите тест с `goleak`, найдите горутину, которая не завершается после отмены
контекста, и исправьте `reportProgress`:

```bash
make leak
```

После исправлений обе последние команды должны завершаться успешно. Изменять тесты не нужно.

## 4. golangci-lint

Каталог: `04-linters`.

Запустите настроенный набор линтеров и исправьте все замечания в `report.go`, не отключая
проверки через конфигурацию или `//nolint`:

```bash
make lint
```

После правок повторите команду и убедитесь, что она не выводит ошибок. Если `golangci-lint` ещё
не установлен, воспользуйтесь способом установки с официального сайта проекта или образом,
который предложит преподаватель.

## Финальная проверка

```bash
go test ./...
make race
make leak
make lint
```

В исходной версии обычный `go test ./...` проходит, а `race`, `leak` и `lint` намеренно находят
проблемы — это и есть материал заданий 3 и 4.

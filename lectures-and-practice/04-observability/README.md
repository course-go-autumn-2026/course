# Занятие 4: observability

90 минут лекции и 90 минут практики: OpenTelemetry Go SDK, трейсы, логи, метрики, SLI/SLO/SLA и Grafana.

- [План занятия](lecture/README.md#маршрут-лекции): порядок тем, тайминг и слайды.
- [Лекция](lecture/README.md): логи и трейсы, настройка OTel, метрики, PromQL и Grafana, завершение приложения, алерты, SLI/SLO и доставка телеметрии.
- [Практика](practice/README.md): запустить сервисы, сгенерировать нагрузку и объяснить неисправности по метрикам, трейсам и логам в Grafana.
- [Запускаемый пример](example/README.md): два отдельных Go-сервиса, общий пакет `telemetry`, Makefile, генератор нагрузки и готовый дашборд.

Сервис заказов резервирует курьера через HTTP. Оба процесса отправляют три сигнала по OTLP/HTTP в Collector. Grafana показывает метрики Prometheus, трейсы Jaeger и логи Loki; из лога можно перейти в трейс.

Окружение на последней версии `tripgoctl` готовим заранее. В обязательной практике код уже инструментирован; собственные спаны, метрики и панели остаются дополнительным заданием. Кейс Avito разбирается отдельно в презентации.

Быстрый запуск из `example/`: `make infra-up`, затем в двух терминалах `make run-couriers` и `make run-orders`. Нагрузка: `make load`. Импорт дашборда: `make dashboard` (без перезаписи существующего). Подробности — в [README примера](example/README.md).

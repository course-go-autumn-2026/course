# Библиотека: Пак 2

BookBridge · 45 минут · Go 1.23+

Перед выдачей библиотека проверяет число экземпляров и сумму платных услуг. Событие выдачи получают каталог и читатель. Лимит экземпляров и доплата за доставку настраиваются для каждой библиотеки.

Отрефакторьте `legacy.go` в `practice.go`, используя указанные паттерны.
Меняйте только `practice.go` и `student_test.go`. Сохраните сигнатуры и готовые тесты;
не вызывайте legacy-функции из нового кода.

Перед началом выполните в папке проекта:

```sh
go test -run '^TestLegacy' ./...
```

Полный набор тестов пока падает на заглушках. Цены - целые рубли.
Зависимости не nil, вызовы последовательные, переполнение исключено.
Слайды и документация разрешены. Сервер и БД не нужны.

## 1. Chain of Responsibility

Реализуйте независимые `CheckCopies`, `CheckTotal`, `CheckLimit`:

- `Copies <= 0` возвращает `ErrEmpty`; `Total <= 0` - `ErrTotal`;
  `Copies > MaxCopies` (5) - `ErrApproval`. Иначе проверка возвращает nil.
- `Chain(checks ...Check) Check` вызывает шаги по порядку, каждый один раз,
  и останавливается на первой ошибке. Сохраняйте причину для `errors.Is`.
  Пустая цепочка возвращает nil.
- `Validate` использует `Chain`: `CheckCopies`, `CheckTotal`, `CheckLimit`.
  Новые шаги подключаются без изменения `Chain`.

## 2. Observer

Реализуйте подписку и публикацию в `Notifier`:

- `Subscribe` сохраняет подписчика без вызова `Update`.
- `Publish` синхронно передаёт исходный `Event` всем подписчикам в порядке регистрации.
  Каждая регистрация даёт один вызов `Update`. Повторы подписки и публикации допустимы.
- Ошибка подписчика не останавливает остальных. Объедините ошибки с сохранением
  всех причин для `errors.Is`. Без подписчиков результат nil.
- Готовый `Issued` публикует статус `"issued"` и `LoanRequestID`.
  `Publish` работает через `Observer`, без привязки к ролям получателей.
  Отправка сообщений, отписка и изменение подписок из callback не требуются.

## 3. Functional Options

Реализуйте `NewLibrary(options ...Option) (*Library, error)`:

- Каждый вызов создаёт новую конфигурацию: `MaxCopies = 5`, `DeliveryFee = 100`.
- `WithMaxCopies(n)` допускает n > 0, иначе при применении возвращает `ErrInvalidMax`.
  `WithDeliveryFee(fee)` допускает fee >= 0, иначе - `ErrInvalidFee`.
- Применяйте любые `Option` один раз, по порядку. Последнее значение поля побеждает.
  При первой ошибке верните nil и исходную причину; следующие опции не вызывайте.
- Готовые `CanHandle` и `TotalWithFee` используют настройки.
  `Validate` из задания 1 сохраняет фиксированный лимит 5.

```sh
gofmt -w practice.go student_test.go

```

Сдайте проект и `TEST_RESULT.txt`. Каждое задание - 1 балл за верное поведение
и применение паттерна. Задания оцениваются независимо. Зачёт - от 2 из 3 баллов,
проект должен собираться. Собственные тесты необязательны.

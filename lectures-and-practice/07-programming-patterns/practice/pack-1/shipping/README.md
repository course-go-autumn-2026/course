# Служба доставки: Пак 1

ParcelFlow · 45 минут · Go 1.23+

Отправитель выбирает конверт или посылку, страховку и бережную обработку. К цене отправления с услугами добавляется стоимость способа приёма: пункт, курьер или срочный курьер.

Отрефакторьте `legacy.go` в `practice.go`, используя указанные паттерны.
Меняйте только `practice.go` и `student_test.go`. Сохраните сигнатуры и готовые тесты;
не вызывайте legacy-функции из нового кода.

Перед началом выполните в папке проекта:

```sh
go test -run '^TestLegacy' ./...
```

Полный набор тестов пока падает на заглушках. Цены - целые рубли.
Зависимости не nil, вызовы последовательные, переполнение исключено.
Слайды и документация разрешены. Сервер и БД не нужны.

## 1. Factory

Реализуйте `Shipment` (`Name() string`, `Price() int`) и фабрику `NewShipment`:

- Ключ `"envelope"` создаёт `Envelope`: имя `"Envelope"`, цена 450.
- Ключ `"parcel"` создаёт `Parcel`: имя `"Parcel"`, цена 550.
- Остальные ключи, включая пустой и другой регистр, возвращают nil и `ErrUnknownShipment`.
  Причина доступна через `errors.Is`. Switch в фабрике допустим.

## 2. Decorator

Реализуйте обёртки `WithInsurance` и `WithFragileHandling` с интерфейсом `Shipment`:

- `WithInsurance` добавляет к имени `" + insurance"`, к цене - 50.
- `WithFragileHandling` добавляет к имени `" + fragile handling"`, к цене - 30.
- Каждый метод вызывает соответствующий метод `Base` ровно один раз.
  Не изменяйте базовый объект и не кешируйте его имя и цену.
- Обёртки работают с любой реализацией `Shipment`, в любом порядке и с повторами.
  `WithFragileHandling` поверх `WithInsurance` на `Envelope` даёт `"Envelope + insurance + fragile handling"` и 530.

## 3. Strategy

Реализуйте тарифы типа `ShippingPrice` (`func(int) int`):
`DropOff` возвращает base, `CourierPickup` - base + 100, `ExpressPickup` - base + 200.

`Checkout` вызывает переданный тариф ровно один раз с исходной суммой и возвращает
результат. Сумма уже включает продукт и услуги, неотрицательна.
`Checkout` не выбирает и не сравнивает тарифы. Новый тариф работает без изменения `Checkout`.

## Сдача

```sh
gofmt -w practice.go student_test.go
go test ./... > TEST_RESULT.txt 2>&1
```

Сдайте проект и `TEST_RESULT.txt`. Каждое задание - 1 балл за верное поведение
и применение паттерна. Задания оцениваются независимо. Зачёт - от 2 из 3 баллов,
проект должен собираться. Собственные тесты необязательны.

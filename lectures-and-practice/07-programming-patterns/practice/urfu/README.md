# Практика к лекции «Паттерны программирования»

Три независимых задания про сервис отчётов. В каждом каталоге есть исходный
код и требования к его изменению. Нужен Go 1.25 или новее, зависимостей нет.

1. [Выгрузка отчёта](01-report-export/README.md).
2. [Хранение отчётов](02-report-storage/README.md).
3. [Готовность отчёта](03-report-ready/README.md).

Команды выполняются из этого каталога.

```sh
go run ./01-report-export
go run ./02-report-storage
go run ./03-report-ready
```

Сдайте изменённый код и кратко объясните, как ваше решение позволяет
добавлять новые возможности.

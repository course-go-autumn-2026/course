# Задание 3. Готовность отчёта

[Сервис](main.go) формирует отчёт, сохраняет его, отправляет письмо и обновляет
панель. Нужно добавить счётчик готовых отчётов. Сейчас каждое новое действие
требует менять `ReportService.Generate`.

## Требования

- После успешного сохранения вызывайте подключённые действия, передавая
  идентификатор отчёта. Сервис не должен знать конкретных получателей.
- Подключайте действия в `main`. Сохраните письмо и обновление панели,
  добавьте счётчик в памяти. Следующее действие должно подключаться
  без изменения сервиса и существующих действий.
- При ошибке проверки или сохранения не вызывайте действия. Ошибку
  передавайте вызывающему коду.
- Выполняйте действия синхронно, в порядке подключения. Пустой список допустим.

Запуск из каталога практики.

```sh
go run ./03-report-ready
```

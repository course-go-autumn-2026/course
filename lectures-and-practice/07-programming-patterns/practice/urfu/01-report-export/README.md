# Задание 1. Выгрузка отчёта

[Сервис](main.go) выгружает отчёт в CSV или JSON. Нужен ещё JSON Lines —
по одному JSON-объекту на строку, с переводом строки после последнего объекта.
Сейчас каждый формат добавляется через изменение `ExportService.Export`.

## Требования

- Вынесите кодирование за пределы сервиса. Он должен проверять запрос,
  вызывать выбранное преобразование и сохранять результат.
- Выбирайте формат в `main`. Добавление нового формата не должно менять сервис.
- Сохраните содержимое CSV и JSON. Имя файла должно состоять из идентификатора
  отчёта и расширения формата.
- При ошибке кодирования не вызывайте хранилище. Ошибки передавайте вызывающему
  коду. Сохраните проверки пустого идентификатора, отсутствия строк
  и неизвестного формата.
- Покажите в `main` выгрузку одних данных в трёх форматах.

Сигнатуру `Export` и способ создания сервиса можно изменить.

Запуск из каталога практики.

```sh
go run ./01-report-export
```

# Задание 2. Хранение отчётов

[Сервис](main.go) сохраняет отчёт через `Storage`. Нужно подключать логирование
сохранения. Позже появится другое хранилище, с которым это тоже должно работать.

## Требования

- Через `log.Logger` записывайте имя файла, число байт и результат сохранения,
  включая ошибку. Имя файла и содержимое должны оставаться прежними.
- Покажите в `main` две сборки приложения — с логированием и без него.
- Сохраните интерфейс `Storage` и реализации `ArchiveService` и `FileStorage`.
  Флаги логирования и проверки типа хранилища в них добавлять нельзя.
- Вызывайте конечное хранилище ровно один раз и передавайте его ошибку
  вызывающему коду.

Запуск из каталога практики.

```sh
go run ./02-report-storage
```
